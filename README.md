# Sociality

A social media web application built with Next.js, TypeScript, and Tailwind CSS.

## Features

- User authentication
- User profiles
- Social media posts and feeds
- Likes and comments
- Followers and following
- Responsive user interface

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Zustand
- REST API

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository and install dependencies:

```bash
npm install
```

### Environment Variables

Configure the backend API URL in your local environment file:

```env
SOCIALITY_API_URL=https://be-social-media-api-production.up.railway.app
```

Do not commit secret keys, access tokens, or credentials.

### Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
